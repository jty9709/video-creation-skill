# 从主题选择风格与工具

## 方向如何成立

先回答“这条片子让谁理解什么、感受什么或采取什么行动”。再决定镜头语言和质感。不要先选工具再把主题塞进工具最擅长的模板。

手法按具体段落和镜头选择，可以跨类型、跨媒介组合。类型名称不是准入条件：实拍与动画、事实讲解与音乐节奏都可以共存；组合后仍需保持内容准确、视觉关系清楚，并遵守用户明确限制。

将方向落实为简短制作说明：叙事视角、情绪走向、主媒介、形状/材质、色彩与明暗、排版、镜头行为、声音角色。没有视觉参考时也要主动设计；无需要求用户先当美术指导。

方向需要一个具体的创意核心，按 [创意开发与视觉验收](creative-development.md) 比较和检验。不要从下表直接选一行便开始生产；表格用于实现选型，不能代替创意开发。

以下是决策线索，不是题材与风格的固定映射：

| 需要解决的问题 | 可考虑的表达方式 | 主要验证点 |
|---|---|---|
| 抽象机制或因果关系 | 动态图解、角色演示、三维剖面、实物比喻 | 状态变化是否真的说明机制 |
| 亲近感、儿童故事、日常情绪 | 二维角色、手绘、黏土感三维、真实生活影像 | 表演与角色一致性，情绪是否可信 |
| 产品材质、结构或使用体验 | 真实素材、三维产品动画、微距与细节剪辑 | 比例、材质、接触、光照与品牌准确性 |
| 历史、人物、纪录叙事 | 有来源的影像/照片、地图、图表、适量重现 | 资料与重现能否分辨，剪辑有无误导 |
| 地形影响行动、兵势对抗、局势逆转 | 三维沙盘、分层地形、阵列/旗帜/城市与俯视局势图的结合，或适合当前情绪的地图影像 | 能否看见阻力、行动与后果，局部戏剧性是否接回可读全局 |
| 音乐、片头、情绪实验 | 动力排版、形态变化、舞蹈/表演、粒子、混合媒介 | 乐句与视觉发展，是否只有重复特效 |

“高级”要拆成可制作的特征：构图主次、真实的空间与材质、细节密度、镜头动机、克制的光效、表演节奏、听觉层次。三维可以是线框、纸雕、黏土、写实或图形化；黑底金线与辉光不自动代表高级。

## 如何读参考

读取整片规格并抽取覆盖全片的画面；在代表性表演、快速运动、转场处读取连续片段。还要听其声音结构，不能只凭截图声称学会节奏。文章中能用的方法要经实际能力验证。

分开记录：用户明确指定的约束、观察到的手法、为当前主题作出的改编。不要把参考中的角色、配色、文案或音乐直接当作本片必须复用的素材。

## 按镜头选择实现

先发现现有工具/API、编辑器、运行环境和素材。可以组合不同路径，但每个组件都应解决实际制作问题。

| 路径 | 适合 | 选用前的小验证 |
|---|---|---|
| SVG / Canvas / HTML、可用的时间轴框架 | 可控角色、图形、字幕、动力排版、界面演示 | 能否精确跳到指定时间，字体是否加载，运动边缘是否稳定 |
| Three.js / WebGL / Blender 或可用三维软件 | 透视、空间运动、产品、光照/材质、骨骼或模拟 | 当前渲染器是否真的支持所需阴影、透明、景深、反射和导出 |
| Manim 或数值绘图工具 | 数学推导、科学图形、数据变化 | 数据、坐标与动画解释是否一致，文字是否过密 |
| 内置生图/生视频、可用图生视频服务 | 复杂插画、真实感、环境、难以手工建模的镜头 | 身份、动作、镜头与参考约束能否保持，是否有闪烁/形变 |
| 实拍/授权素材 + 剪辑/合成工具 | 真实世界、纪录片、演示、叙事蒙太奇 | 素材分辨率、节奏、来源、颜色与视线匹配 |
| FFmpeg、音频处理/合成工具、可用配音/音乐能力 | 合成、编码、剪辑辅助、音频制作 | 编码可用、音轨时长正确、无丢帧/削波 |

程序化绘制不是质量上限，也不是唯一入口。直接导出可复现的程序画面、离线三维渲染、时间轴剪辑、视频生成都可以。高质量位图不等于可用动画；真实 Three.js 场景也不意味着最终画面已有完整光照材质。

题材已经提出明确的空间或表演需求时，先验证能支持该需求的制作路径。三维沙盘要有可读的地形体积、遮挡、投影与路线贴合；平面地图上的山纹、旋转或缩放不能证明这些能力。可读性可以通过俯视镜头、标签和阶段全景保留，不必为了信息清楚放弃题材需要的表现力。

若首选能力不可用，选择仍能达成相同表达目的的路径，先验证最困难的镜头。需要更换用户明确指定的风格、人物、时长或交付物时再沟通，不把失败静默降级成静态图轮播。不要捏造不存在的接口、把密钥写进工程，或让素材生成请求隐含发布/付费授权。
