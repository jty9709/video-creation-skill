# 动作、资产与连续性

## 镜头内有发展

用动词描述镜头：拆开、靠近、观察、抓起、转身、汇聚、碰撞、变形、完成。明确开始与结束的可见状态。次级动作服务主动作；镜头跟随、前后景视差、呼吸或粒子本身不能替代该发生的事件。

动作不必平均分段。根据重量、情绪和节奏安排加减速、停顿、预备与惯性。拿起东西要有接近、接触、受力和离开；落地要有支撑和重心变化。动作终点需要让观众读到结果。

## 让动作具有性格

本节用于需要设计运动、图形变形或表演的部分；普通实拍、访谈和录屏不因此必须添加动画。先尊重原素材的真实时间与动作关系，必要的节奏调整可通过选择、剪辑与留白完成。

先确定运动的意图和物性，再选择曲线。重物有加速与受力，弹性对象可有挤压拉伸和衰减回弹，机械对象重视轴心、节拍与锁定，流动对象重视轨迹和速度连续。文字、图形也可以借用这些性格，但要保持可读的形状。不要把同一种 `smoothstep`、弹簧或匀速漂移应用到整片。

对关键动作明确三个可观察时刻：准备从何处开始、什么时刻发生主要事件、结果何时稳定。主事件可以是接触、最大伸展、方向改变、图形替换或精确归位，按表达需要选择。用少量跟随、错峰、惯性和恢复让动作有层次；避免所有元素同一瞬间、同一速度一起动，也不要用随机延迟破坏清楚的主落点。

需要准确落在某个锚点时，从该时刻倒排接近过程，让落点后的回弹或余势延续；不要到锚点才启动一段很慢的过渡，却把它记为已经落位。逐字、群体或连锁动作可使用有组织的错峰。音乐明确给出细分时可借其安排，普通叙事也可由视线、接触、因果或呼吸决定，不必强套拍格。

变形对象需要稳定对应关系：形状之间统一采样数、方向与起点，粒子/群体保留个体身份，关节保留轴心。文字先按字形度量、基线和字距排好，再施加有意变形；过渡中夸张可以成立，关键阅读时刻必须恢复预定轮廓，不能把随意拉伸到方框的排版误差称为弹性。

## 可重现的时序与状态

程序动画：

- 统一全局时间与镜头局部时间，事件写成数据而非零散延迟；边界上使用同一位置、姿态与可见性定义。
- 通过共享对象、形状匹配、运动方向、遮挡或声音桥连接镜头。剪切可以有意跳变；连续转场不能意外瞬移、增生或变色。
- 区分主体、相机、特效和文字的时间。场景早退条件、淡出门控和父层透明度也会让本应停留的结果提前消失。
- 渲染固定时间点，验证随机种子及模拟缓存。两次访问同一时刻应得到相同状态；不得靠实时运行积累才能得到正确帧。

## SVG / 二维角色

简单造型优先考虑可控的矢量或骨骼绑定；不强制所有角色都改成几何图标。

- 面部结构统一设计：眼窝、瞳孔、眼睑、鼻口与脸部角度一致。转头不是把一套正脸五官平移到侧脸上。
- 层级、旋转轴和遮挡符合身体结构；手臂两节、腕与道具、腿脚支撑点持续连接。抬手时检查肘部，行走时检查脚底滑动与膝盖方向。
- 视线指向有意义的目标，眨眼和表情随情绪/语义变化。语音能量只能驱动粗略开合，不能把它称为音素级口型同步；需要清晰近景口型时使用更细的对齐或专门能力。
- 检查角色全动作范围的裁切、描边粗细和遮罩接缝。尾巴、耳朵、头发和衣物的次级运动保留连接点。

## 生图、连续帧与生成视频

先定义角色/物体的稳定特征：轮廓、比例、配色、材质、五官、服装、光源方向、视角和背景规则。保存母版与生成条件；需要时做转面或姿态参考。

根据动作复杂度选择路径：

- 可绑定的独立部件：一致的分层素材 + 骨骼/形变，处理接缝与遮挡。
- 局部表情：匹配角度和比例的表情/眨眼帧，先对齐再替换；不要把明显不同透视的脸贴在原头上。
- 大幅转体、透视变化、遮挡或复杂表演：足够密集且一致的连续帧、三维绑定，或当前可用的视频生成能力。少数无关姿态之间淡化不构成连续动作。

生成连续帧时覆盖动作关键相位与必要中间相位，保持身份与镜头条件。逐张检查帧序列，再按预定帧率播放检查速度和闪烁；连续生成也可能逐帧漂移。补帧只能改善已经一致的轨迹，不能修复错误解剖、凭空多出的肢体或换脸。

用户要求简单 SVG 时不必调用生图；用户要求复杂生成动画时不能用整张静态插图的小幅摆动冒充完成。

## 三维与镜头

- 真实透视、遮挡、尺度和接触是空间感的基础；前后物体可通过视差、亮度、雾、焦点或细节密度区分。
- 选用可支持目标效果的渲染路径。仅把三维投影线段画到二维画布时，检查深度排序、近裁剪与遮挡；不要宣称得到并未实现的实体阴影或物理材质。
- 运镜围绕叙事焦点：接近发现、跟随行动、环绕揭示结构、退出呈现结果。避免镜头与物体同时任意漂移导致无稳定参照。
- 强光、辉光、景深保留可读主体。快速运动的时间采样与模糊按 [渲染复核](render-and-review.md) 处理；不要统一模糊整张画面。
- 线框主轮廓、内部结构和背景不应同亮同粗。材质片要检查反射变化、光源和物体形状是否吻合，不能只增加粒子来声称质感提升。

## 来自实际制作的易漏问题

| 现象 | 检查与修正方向 |
|---|---|
| 小动物五官单看精细，组合后怪异 | 放大看眼睑/瞳孔与脸部透视；检查整套睁闭眼帧，必要时重做统一面部 |
| 词元飞走但含义没发生 | 显示源与目标语境，检查路径与实际落位，保留完成后的阅读时间 |
| 转场正拍近乎空黑，声音已爆发 | 看边界前后连续帧；调整可见事件和入场时序，保留可追踪对象 |
| 数字、标签挤在运动主体上 | 在运动全路径检查，调整位置、引线、布局或镜头，不能只改中间一帧 |
| 结尾结果提前消失 | 检查父层/早退/片段长度/字幕门控；重新导出并复看尾部 |

这些是定位线索，不要求每条片都出现猫、词元、亮点或线框。
